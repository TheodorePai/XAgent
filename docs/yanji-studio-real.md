## 三日行程概览

**第1天：市区初识、双语街区与冷面**
- 上午：把行李放到住处后，步行游览延边大学周边，校门口的双语招牌“网红弹幕墙”适合拍照（校园能否进入需现场确认）
- 午餐：延吉冷面，荞麦面、冰碗冷面配苹果片、牛肉、泡菜
- 下午：延边博物馆，了解朝鲜族与延边地方史。这处信息来自网页的读者补充，开放与预约需核实
- 傍晚至晚上：沿布尔哈通河散步，回来再看招牌亮灯，晚餐吃延吉烧烤

**第2天：民俗园与帽儿山轻徒步**
- 上午：中国朝鲜族民俗园，看青瓦白墙的传统民居、长鼓舞与农乐舞，也可租朝鲜族服饰拍照（网页写门票约30元，非实时）
- 午餐：朝鲜族包饭，苏子叶包五花肉、米饭、蒜片、辣酱
- 下午：打车去帽儿山国家森林公园，走常规步道登顶俯瞰全城，预留约2小时往返
- 晚餐：参鸡汤，饭后在人民公园一带散步

**第3天：早市、西市场与返程**
- 清晨：水上市场（网页写约5:00—8:00，需核实），吃打糕、米肠、喝豆浆面
- 上午：西市场一带买打糕、辣白菜等伴手礼，顺路看看延吉天主教堂外观
- 中午：石锅拌饭或包饭收尾，按高铁或航班时间提前去延吉西站或朝阳川机场
